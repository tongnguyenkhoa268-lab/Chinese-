Nhập OpenAI API key

Key chỉ lưu trong trình duyệt của bạn (localStorage) và được gửi trực tiếp tới OpenAI mỗi khi tạo bài/chấm bài — trang web không lưu hay nhìn thấy key này ở đâu khác.

Lưu ý quan trọng: đây là ứng dụng chạy 100% trên trình duyệt, không có server riêng. Nếu bạn public trang này lên internet (ví dụ GitHub Pages) và người khác mở lên dùng, họ sẽ phải nhập key của họ — đừng để lộ key của chính bạn trong code hoặc chia sẻ cho người khác dùng chung.
